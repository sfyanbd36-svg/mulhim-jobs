# ملهم — وظائف بغداد والعراق 🇮🇶

صفحة الوظائف العامة لبوت **ملهم** للتيليجرام: وظائف محلية موثوقة من شركات مسجّلة + 60 وظيفة من السوق العراقي، تتحدث تلقائياً كل 6 ساعات.

- 🤖 **البوت**: https://t.me/mulhimstudio_hr_bot
- 🏙️ وظائف بغداد، البصرة، الموصل، أربيل وكل المحافظات
- 📄 سيرة ذاتية PDF جاهزة داخل البوت مجاناً
- 🎯 ترشيح وظائف يطابق مدينتك ومهاراتك (`/match`)
- 🔔 تنبيه فوري بأي وظيفة جديدة تناسبك (`/follow`)
- 🚀 للموظف: تقديم سريع بسيرتك المحفوظة بزر واحد
- 📊 لمتابعة طلبك: `/mystatus`

للشركات — انشر وظيفتك برسالة وحدة والبوت يوزعها فوراً: `/company` ثم `/postjob`.

كلشي مجاني، مصمم للسوق العراقي.
